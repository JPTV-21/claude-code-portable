5|# 功能:
6|#   1. 自动识别当前操作系统与 CPU 架构
7|#      Windows / macOS / Linux，x64 / arm64（Linux 会自动识别 musl）

10|#      - Claude Code 放在 ./bin/<arch>/<platform>/claude[.exe]
11|#   3. 首次运行 ClaudeX 生成 claudex-config.json，随后立即关闭它

20|#   ./bin/<arch>/<platform>/claude*      Claude Code 本体
22|# 三平台支持:

220|一键部署便携版 ClaudeX + Claude Code。脚本会把 ClaudeX 放在脚本所在

225|ClaudeX、data/ 和 bin/ 的根目录。
227|选项:
228|  -u, --update             强制重新下载最新版 ClaudeX 与 Claude Code
229|      --no-claudex         跳过 ClaudeX 的下载/更新
230|      --no-claude          跳过 Claude Code 的下载/更新
231|      --platform OS        安装平台：windows/macos/linux/all（默认检测）
232|      --arch ARCH          CPU 架构：x64/arm64/all（默认检测）
233|      --all                下载全部 6 个平台/架构组合，每项一个子目录
234|      --install-dir DIR    安装目录（默认脚本所在目录）
235|  -y, --yes                使用默认值，不进行交互询问
236|      --claudex-repo REPO  指定 ClaudeX 仓库（owner/repo）
237|      --claudex-asset NAME 指定 ClaudeX release 中的资产文件名
238|      --claude-repo REPO   指定 Claude Code 仓库
239|                           （默认 anthropics/claude-code）
240|      --timeout SECONDS    等待 ClaudeX 生成配置文件的秒数（默认 20）
241|  -h, --help               显示本帮助
243|环境变量:
244|  GITHUB_TOKEN / GH_TOKEN  提高 GitHub API 速率限制
245|  CLAUDEX_REPO             覆盖 ClaudeX 仓库地址

248|  NO_COLOR                 禁用彩色输出
